# hotel_analytics


Base de datos y dashboard BI para análisis de ocupación,
ingresos y servicios de un hotel con datos de todo 2026.

## Tecnologías
- SQL Server
- Power BI Desktop (DAX, diseño oscuro profesional)

## Contenido
- `hotel_analytics.sql` — 5 tablas, 2 views y consultas de análisis
- `dashboard-hotel.pbix` — Dashboard de 2 páginas con tema oscuro

## Dashboard
- Página 1: Resumen Ejecutivo — KPIs, evolución mensual, canales de reserva
- Página 2: Servicios & Huéspedes — análisis por servicio, país y tipo de habitación

## Datos destacados
- 120 reservas anuales con estacionalidad real
- Temporada alta: enero, febrero, julio, agosto y diciembre
- 6 tipos de servicios adicionales
- Huéspedes de 9 países diferentes
